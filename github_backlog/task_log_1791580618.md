## 5. Where the Errors Started Piling Up (Root-Cause Chain)

1. **Session fragmentation (Transcript A, 01:19).** The user asked to "move the 2 tasks over to this chat." The assistant explained tasks are session-bound and **cannot be adopted**. From this moment on, work escaped its original context — hence chart paths pointing at the *old* brain folder. **All subsequent debugging lost state.**

2. **The 5-min feed bug was never diagnosed.** The transcript's last act is reading `daemon.py` lines 1–50 and then stopping. A broken *data-level* problem (the thing that feeds every downstream score) was left open. Everything after inherits corrupted/absent 5m data.

3. **The "patch culture" replaced the engineering.** The repo contains **15+ `patch_*.py` files** (`patch_agent`, `patch_daemon_prompt`, `patch_discord`, `patch_divergence`, `patch_evaluate`, `patch_finditer`, `patch_macro`, `patch_momentum`, `patch_stock_tools`, `patch_style`, `patch_v2`, `patch_v3`…). Versioned generators run to `v11`. This is the signature of **iterative in-place mutation, not a stable pipeline.** Transcript C's "self-healing modifications after every scan" institutionalizes this churn.

4. **The engine-quantization smoking gun (Transcript C).** The Optimization Agent itself flagged "Scores cluster on {40, 60, 65, 80}" and "1D Score = 0 for NCLD." The assistant's fix was to **inject a fractional RSI modifier** (`score += int((rsi - 50) * 0.15)`) and change a `0` fallback to `40`. That is **cosmetic de-clustering of a scoring bug**, not a mathematical correction — it makes scores *look* varied without proving the underlying signal is real. This is precisely the "confusion origin" the user later feared: numbers moving for the wrong reason.

5. **The gate never opened.** In Transcript C the scan returned **0 qualifying setups out of 21**; highest was OUST at 71%. Because the score math was quantized and the 1D layer was stubbed to 0/40, the >80% gate was effectively **unreachable by construction.** The system was tuned to say "no signal" — a silent failure dressed as rigor.

6. **The dashboard diverged from reality.** By the time the build was inspected, `dashboard.py` was proudly showing "DeepSeek Uplink: CONNECTED, Ping: 45ms" — a **hard-coded string** — while the actual pipeline was blind (HTTP 403 rate limit) and the data feed was broken. The UI reports health the system does not have. This is the single most dangerous discrepancy: **false green lights.**
